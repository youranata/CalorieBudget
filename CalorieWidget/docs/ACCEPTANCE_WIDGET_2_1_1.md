# 2.1.1 小部件入口验收

日期：2026-11-24。对照基线：2.1 版本。版本：2.1.1（versionCode 5）。

## 调整范围

- 常规及紧凑 Widget 均移除独立的“备注来源”入口及其 PendingIntent，清理仅供此入口使用的文案和背景资源。
- kcal/kJ 两个按钮的高度从 28dp 改为 48dp，文字从 12sp 改为 14sp；按钮上方留 4dp。合计仍占原来的 52dp，余额、kJ 和已摄入/预算区域的空间与自动字号范围保持。
- 两个按钮仍打开同一个录入页并预选对应单位；录入页的自由备注、保存、取消、编辑功能保持。

全部 Activity、录入页 XML、数据库、计算、日期、历史、图表、闹钟和 App 样式均与 2.1 逐字节相同。Provider 仅移除备注入口并简化输入 Intent 的参数，两个单位入口、余额入口、刷新和尺寸判断保持。应用 Gradle 仅递增版本。

## 验证

```bash
./scripts/check.sh test assembleDebug lintDebug
python3 -m unittest discover -s scripts -p 'test_audit*.py' -v
```

- `test assembleDebug lintDebug` 实际执行成功；Debug、Release 各 **79 项测试通过**，失败、错误和跳过均为 0。
- 新增完整点击与 Room 保存验收在 API 26 和 35 上运行：常规/紧凑两种尺寸分别通过 kcal/kJ 入口打开录入页，核对预选单位、备注输入、重复点击保存仅写入一次、备注持久化及混合单位总量。其余计算、编辑、删除、日期与历史回归通过。
- Native Graphics 实绘并查看两种 Widget 在浅/深色、正常/大额负余额下的 **8 张截图**；最小尺寸下两个按钮均有 48dp 点击高度，数值和辅助文字不省略、不截断，余额入口正常。
- 既有审计与隐私扫描器的 **26 项 Python 测试通过**；单独范围检查确认所有 Activity、录入页、数据库、计算、图表和闹钟文件未修改，Provider 和布局的差异仅为上述授权内容。

本次属于用户明确要求的入口精简；旧版“只改外观”的审计脚本仍保留原有约束，没有放宽检查器来声称全部入口未变。另以本轮 Git 基线进行单独范围核对，确认仅发生上述授权调整。
