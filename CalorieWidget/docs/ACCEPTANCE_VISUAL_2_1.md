## 视觉调整

保持低饱和度，以鼠尾草绿为主色，搭配雾蓝、暖沙和灰紫。余额区用雾色渐变、轻微高光与无数据含义的细线装饰建立层次；日期、记录时间、输入单位、次要操作与只读提示使用统一的色面。浅色使用偏暖纸色，深色使用蓝灰底色。数字采用等宽数字特性和更清晰的字重层级，按钮、输入框、记录行与图表区域统一留白和圆角。

五个 App 页面、常规及紧凑 Widget 均同步细化。Widget 仍保留余额、kcal、kJ、备注四个入口。装饰仅由原生 XML Drawable 构成，不引入图片、图表算法、权限或依赖。

继续应用 [Mobile App UI/UX Design skill](https://github.com/ceorkm/mobile-app-ui-design) 中的视觉层级、克制配色和组件一致性建议；没有采用增加文案、功能或流程的建议。Skill、下载材料、脚本中间结果和截图集中在本地忽略的工具或构建目录，不进入 Git。

第一阶段源码提交：`f202db4`。第二阶段补充放大字体验收、完成独立复核并更新交付 APK。每次推送前均检查外层及工程内两份 README 和两份 `.gitignore`。
